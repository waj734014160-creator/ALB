# ADR-0007：接口重构必须保留已验证数值算法

## 文档角色

- 角色：数值算法与接口重构边界的架构决策。
- 状态：Accepted。
- 允许更新：算法保留原则、数值变更立项条件、参考合同和发布门禁。
- 禁止更新：单次运行日志、临时调试过程和未经验证的新算法结论。
- 相关文档：`docs/migrations/0.4.1.md`、
  `docs/migrations/0.4.1_test_map.json`。

## 背景

0.4.0 将旧分析类收敛为 `bearing.analysis` 时，静平衡、动态系数和谐波
线性化被接口重写同时替换了内部数值方法。其中通用 root、单轨迹四参数最小
二乘和轨迹拟合线性化没有与迁移前算法做双侧数值对比。这种改变超出了接口
重构范围，也使通过生命周期和 API 测试的代码仍可能给出不同数值结果。

## 决策

1. DTO、生命周期、对象所有权和用户 facade 可以重构；已经实现并通过数值
   证据验证的核心算法不得在同一重构中替换。
2. 静平衡保留专用的阻尼 Newton、偏心率圆域限制、冻结 Jacobian、停滞后
   固定刚度回退、内层收敛门禁和最终点重新计算。
3. 动态系数保留正反涡动的复数 `recognize_kc()` 识别，不以单轨迹最小二乘
   替代。椭圆空间旋转与时间相位分别表达。
4. 谐波线性化保留压力方程导数、节流流量到压力耦合、阀芯到力 Jacobian 和
   原四瓦方向聚合；只开放已有参考覆盖的量纲液膜和三节点 CSOrifice 主动
   润滑拓扑。
5. 确定性数值路径必须从修改前固定提交冻结输入、完整数组和环境元数据，并
   使用精确相等回归。参考一经提交，修复过程不得重新生成以迎合实现。
6. 若确需改变核心算法，必须单独立项，明确物理或数值理由，冻结旧算法和新
   算法两侧参考，并证明差异合理后才能合并。接口重构、代码整理或性能优化
   本身不构成更换算法的理由。
7. 任一内层或轨迹样本不收敛时，不得发布伪造的成功结果；稳定异常必须携带
   最后可信状态和完整失败快照。
8. simulation 的转子、mount、嵌套 `MultiPad` 及物化控制/阀/热组件必须使用
   同一归一化 `time_step`，防止接口重构制造不同内部时间尺度。
9. 未经验证且不属于当前正式轴承族的倾瓦实现从 0.4.1 wheel 物理删除；未来
   若重新加入，按新功能重新设计、冻结参考和验收。

## 影响

- `EquilibriumOptions` 是公开不可变配置，但只映射原静平衡算法参数。
- `dynamic_coefficients()` 仍保留友好的单轨迹入口，内部自动构造独立的正、
  反涡动 runtime。
- `harmonic_linearize()` 不再接收轨迹拟合所需的 `amplitude` 和
  `points_per_cycle`。
- 配置 schema 和 surrogate package 继续使用 0.4.0；本次只升级 Python 包
  版本为 0.4.1。
- 0.4.0 标签、wheel、manifest 和验收报告保持历史不变；0.4.1 使用独立的
  V4P 功能编号和数值合同。

## 修订关系

本文补充 ADR-0006 的“数值公式保持不变”原则，并把它升级为可执行的参考冻结
与发布门禁。ADR-0006 的无 legacy、友好 API 和严格配置边界继续有效。
