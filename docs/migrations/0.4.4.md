# ALB 0.4.4 根 API 易用性更新

参考来源：`ALB/__init__.py`、`ALB.api.SCHEMA_VERSION`、公开 API 测试和实际验证输出。

## 版本边界

Python 包开发版本升级为 `0.4.4`。JSON5 `schema_version` 和 surrogate package
格式继续使用 `0.4.0`；现有合法 0.4 配置与模型包无需迁移。0.4.4 尚未形成固定
发布候选、标签或 detached 发布验收。

## API 更新

`SCHEMA_VERSION` 从已有 `ALB.api` facade 显式提升到包根：

```python
import ALB

print(ALB.__version__)       # 0.4.4
print(ALB.SCHEMA_VERSION)    # 0.4.0
```

`ALB.__version__` 描述当前安装的 `re-alb` 发布版本；`ALB.SCHEMA_VERSION` 描述
bearing 与 simulation JSON5 接受的严格配置契约。二者独立演进，不应互相推导。
本轮不改变配置解析、数值路径、高级 namespace 或 optional dependency 边界。
