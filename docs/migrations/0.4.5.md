# ALB 0.4.5 伺服阀接口更新

## 文档角色

- 角色：0.4.4 到 0.4.5 的稳定伺服阀配置迁移说明。
- 允许更新：0.4.5 公共配置、迁移规则、参考和真实开发验证。
- 禁止更新：历史发布证据、未经执行的发布结论和外部实时状态。
- 事实来源：`ALB/api/config.py`、`ALB/api/building.py`、
  `ALB/config/control_models.py`、`ALB/control/valve.py` 和 0.4.5 参考测试。

## 版本边界

Python 包版本为 `0.4.5`，JSON5 `schema_version` 继续为 `0.4.0`。本次只收敛
主动轴承的伺服阀配置，不改变轴承压力、液膜、控制器或转子耦合算法。旧
0.4 配置如果使用 `response_time`、`third_order_time_constant`、`third_order`
或 `static`，必须显式迁移后才能由 0.4.5 加载。

## 二阶伺服阀

```json5
valve: {
  model: "second_order",
  natural_frequency_hz: 166.0,
  damping_ratio: 0.7,
  delay: 0.0,
}
```

旧 `response_time` 实际是 `tw`，迁移公式为：

```text
natural_frequency_hz = 1 / (2*pi*response_time)
```

## 任意传递函数伺服阀

```json5
valve: {
  model: "transfer_function",
  numerator: [b_m, ..., b_1, b_0],
  denominator: [a_n, ..., a_1, a_0],
}
```

系数按连续时间 `s` 的降幂排列。分子包含完整增益及任何有理延迟近似；该模型
不再接受独立 `delay`。传递函数必须 proper。原静态阀迁移为：

```json5
valve: {
  model: "transfer_function",
  numerator: [1.0],
  denominator: [1.0],
}
```

## 能力边界

- 量纲和无量纲主动轴承时域运行支持两种新配置。
- 内部静态阀仍用于静平衡和直接阀芯输入。
- 解析谐波 runtime 继续只接受标准二阶阀；任意传递函数的解析谐波扩展不属于
  本次接口重构。
