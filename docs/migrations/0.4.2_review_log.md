## 第一轮：数值与 API

- 审查日期：2026-07-24。
- 审查输入：0.4.1 实现候选 `a26435e...` 到初始 0.4.2 修复
  `f063731` 的完整 diff。
- 独立关注点：合法路径逐元素一致、拒绝发生在求解前、adapter local dt 与
  物化组件一致、异常类型和 failure snapshot 完整。

发现并关闭两项 P2，没有 P1：

1. `R1-P2-01`：复数 `time_grid` 会在 `np.asarray(..., dtype=float)` 中丢弃
   虚部并可能产生 warning，而不是在轨迹 runtime 创建前稳定拒绝。修复为先
   检查复数输入并抛出 `TypeError`；新增 pre-runtime 计数测试。
2. `R1-P2-02`：`matrix_rank()` 或 `cond()` 的 SVD 诊断异常没有稳定错误边界，
   会泄漏原始 `LinAlgError`。修复为 `CalculationError`，snapshot 保存双轨迹、
   复位移矩阵、目标/实际频率、Nyquist 和异常类型。

修改位置复读后未发现新的 P1/P2。第一轮复验：
