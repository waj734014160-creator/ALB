# ALB 0.4.0 不兼容迁移手册

## 文档角色

- 角色：稳定版本迁移手册。
- 目的：说明从 0.3 升级到 0.4 时必须完成的源码、配置和模型迁移。
- 允许更新：0.4 公共契约、迁移边界、仓库外工具和稳定验收入口。
- 禁止更新：实时任务状态、临时日志和未经验证的结果。
- 更新时机：0.4 公共接口或迁移工具变化时。

## 迁移原则

0.4 不在 wheel 内兼容 0.3。升级必须先在旧环境中转换配置和模型，再安装
0.4；不要期待弃用警告、自动字段推断或旧 import 转发。

## Python API

| 0.3 形态 | 0.4 入口 |
| --- | --- |
| builder/factory + runtime `init()` | `ALB.build_bearing(config)` |
| 文件 workflow builder | `ALB.bearing_from_file(path)` |
| `input/evaluate/output` 普通用法 | `Bearing.calculate(...)` |
| `StaticPosition` | `bearing.analysis.find_equilibrium(...)` |
| orbit helper | `bearing.analysis.trace_orbit(...)` |
| dynamic character helper | `bearing.analysis.dynamic_coefficients(...)` |
| harmonic helper | `bearing.analysis.harmonic_linearize(...)` |
| mutable rotor-bearing coupler | `ALB.build_simulation(SimulationConfig)` |
| legacy save/export fallback | immutable result `.write(path)` |

高级领域代码仍可使用严格 DTO 的 `input/evaluate/output/step`，但不能调用
`init()` 或依赖 Signal/adapter。

## 配置

每个文件必须包含：

```json5
{
  schema_version: "0.4.0",
  kind: "bearing",
  includes: [],
  spec: {},
}
```

必须删除旧 `share_name`、`n/pt`、`alb/servo/switch`、`thermal_enabled`、平铺
controller 字段、重复 dt、实现类标签和无作用字段。轴承族只允许
`liquid_film`、`active_lubricated`、`gas_film`、`multi_pad`、`surrogate`。

控制模式映射为 `pid`、`fuzzy_pid`、`uncontrolled`、`external_spool`；阀模型
映射为 `second_order`、`third_order`、`static`。`thermal: null` 表示关闭；
对象表示启用，`transient_enabled` 必须为 bool。

液膜不再声明动压/静压/混合。节流孔必须在 `restrictors` 中构造期给出；空值
表示无节流耦合。

## ALBNN package

运行时只接受 `alb.surrogate-package.v0.4`：

```text
manifest.json
weights.pt
input_scaler.npz
output_scaler.npz
metadata.json
```

旧 package 和 pickle scaler 不可加载，也不存在 `trust_pickle`。仓库中的
`tools/migrations/migrate_surrogate_0_4.py` 只用于升级前转换可信旧制品，并且
必须显式传入 `--trust-legacy-pickle`；它不安装到 wheel。

新训练流程必须直接输出 v0.4 package，松散 checkpoint/scaler 不能作为正式部署
输入。

## 外部消费者

- SURROGATE_TRAIN 直接安装候选 wheel，并使用公开 facade、v0.4 package 和模块化
  remote 命令。
- PAPER_WORK 的活跃脚本和配置迁移前必须先建立哈希清单及恢复快照。
- 历史 refs、outputs/results、日志、remote payload 和图件数据不修改，也不计入
  active-source legacy-zero。
