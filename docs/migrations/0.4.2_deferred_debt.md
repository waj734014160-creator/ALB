# ALB 0.4.2 明确保留债务

## 文档角色

- 角色：0.4.2 范围外维护债务记录。
- 允许更新：已确认债务的影响、适用边界、证据位置和后续关闭条件。
- 禁止更新：把未验证猜测写成缺陷、顺带修改数值算法或记录实时任务状态。
- 事实来源：分层 mypy 门禁、源码 TODO 和 0.4.2 两轮审查。

## 实现层 mypy 基线

分层门禁对稳定边界执行 strict mypy；其余 144 个安装源码文件保留 363 条诊断、
85 个文件/错误码组的精确基线。本轮没有扩大基线。该债务主要位于旧数值实现
和训练实现，不代表 0.4.2 新增接口存在类型错误，但会降低内部重构时的静态保障。

后续只能在独立维护版本中逐组减少；不得通过新增 ignore、放宽 strict target
或扩大 baseline 关闭门禁。
