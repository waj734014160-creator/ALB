# ALB 0.4.6 控制周期与 ROS2 耦合积分器

参考来源：`ALB/api/config.py`、`ALB/api/building.py`、`ALB/api/simulation.py`、
  `ALB/core/time.py`、`ALB/dynamics/ros2.py`、
  `docs/adr/0009-controller-sampling-period-and-ros2-integrator.md` 和 0.4.6 参考测试。

## 版本边界

Python 包版本为 `0.4.6`，JSON5 `schema_version` 和 `ALB.SCHEMA_VERSION` 继续为
`0.4.0`。本次新增三个可选配置字段：`control.control_period`、
`time_grid.integrator` 和 `time_grid.jacobian_refresh`。新增根符号
`ALB.TimeStepAdjustedWarning`，根 API 共 28 个符号。新增高级导出
`ALB.dynamics.Ros2Options`。合法的 0.4.5 配置无需迁移；不写新字段时仍使用
staggered 积分器和逐步控制，数值结果和结果元数据与 0.4.5 逐位一致。

ADR-0007 第 8 条要求全部组件共享同一步长。本次只为控制器采样增加受限例外：
转子、mount、嵌套 `MultiPad`、阀和热模型仍共享同一步长。ROS2 是可选积分器，
不替换默认 staggered 算法。决策依据见 ADR-0009。

## 控制器采样周期

`active_lubricated` 的 `pid` 与 `fuzzy_pid` 可声明控制器采样周期 `Ts`。单位与
`time_step` 相同，量纲轴承为 s：

```json5
spec: {
  family: "active_lubricated",
  unit_system: "dimensional",
  time_step: 2.0e-5,
  control: {
    mode: "pid",
    frequency_hz: 50.0,
    sensor_angles_deg: [45.0, 135.0],
    gains: {kp: 1.0, ki: 0.0, kd: 0.0, feedforward: 0.0},
    control_period: 1.0e-3,
  },
}
```

上例中 `m = Ts / time_step = 50`。控制器每 50 次求值运行一次，其余求值保持上一
指令，即零阶保持。阀、液膜和节流器仍按 `time_step` 推进。PID 与模糊 PID 的内部
离散化使用 `Ts`（`PIDConfig.control_period`、`FuzzyPIDConfig.control_period`
和 `sample_period`）。省略字段或写 `null` 时 `Ts = time_step`，行为与 0.4.5
相同。`uncontrolled`、`external_spool` 或其他模式写该字段，会被
`ConfigurationError` 拒绝。

独立轴承（`ALB.build_bearing()`）要求 `r = Ts / time_step` 为正整数，判据为
`|r - round(r)| <= 1e-9 * r`，否则构建前报 `ConfigurationError`，不自动改写。

采样按求值次数计数，并假定每次求值相隔一个 `time_step`。耦合仿真中第 `k` 次求值
就是第 `k` 步，这一假设自然成立。独立调用 `Bearing.calculate()`、
`BearingAnalysis.trace_orbit()` 或动态系数网格时，只有按 `time_step` 间隔求值，
`Ts` 才有物理意义。静平衡和谐波分析使用静态求值，会重置控制器并重新开始采样
相位。

## 仿真步长调整

`SimulationConfig` 先检查请求配置：`rotor.dt` 和每个 bearing-local `time_step`
必须等于请求步长 `h`。随后，各 mount 中声明的 `Ts` 经 unit adapter 换算为全局
秒。若 `h` 整除全部 `Ts`（相对容差 `1e-9`），配置不变；否则保持 `Ts`，并按下式
调整：

```text
h' = Ts / ceil(Ts / h)            （h > Ts 时 h' = Ts，m = 1）
m  = Ts / h'
steps' = m * ceil(T / Ts)          T = steps * h
```

取整时先从 `T / Ts` 中减去 `1e-9 * max(1, T / Ts)`，因此 `T` 已经是 `Ts`
整数倍时不会因浮点尾差多出一个控制周期。

例如 `Ts = 1e-3 s`、`h = 3e-5 s`、`steps = 1010` 时，`m = 34`，
`h' = 1e-3/34 ≈ 2.941e-5 s`，`steps' = 1054`。结束时间从请求的 `0.0303 s`
变为 `0.031 s`。

调整发生时：

- 全部轴承配置按 `h'` 重建并重新校验；内联 `MultiPad` 子瓦同步改写。文件引用的
  子瓦无法自动改写，直接报 `ConfigurationError`，此时应选择 `h = Ts / m`。
- 全部校验通过后先发出 `ALB.TimeStepAdjustedWarning`。它是 `UserWarning` 子类，
  不是 `ALBError`；`adjustment` 属性记录 `requested_time_step`、
  `requested_steps`、`requested_end_time`、`control_period`、`time_step`、
  `control_steps_per_period`、`steps`、`end_time` 和 `rule`。
- 警告之后，同一个转子对象才原位重新离散并重置状态。转子必须提供 owner hook
  `_retime_for_owner(dt)`（`RossRotor` 提供），缺少时在警告前报
  `ConfigurationError`；重新离散本身失败时，在警告之后报 `ConfigurationError`。
  警告之前被拒绝的配置不修改转子。
- `SimulationConfig.time_step`、`steps`、`rotor` 和 `mounts` 保存实际生效值。
  `time_step_adjustment` 与警告中的映射相同；`control_periods` 按声明列出
  `mount`、`path`、`local_control_period`、`control_period` 和
  `control_steps_per_period`。

配置多个不同 `Ts` 时，只接受同时整除全部周期的 `h`，不做自动调整。需要把调整视为
错误时，可用 Python warnings filter 把 `ALB.TimeStepAdjustedWarning` 提升为异常；
警告在重新离散之前发出，因此此时配置被拒绝，转子保持不变。

转子被某个 `SimulationConfig` 重新离散后，若另一个按原步长校验的
`SimulationConfig` 仍持有同一转子，用它构建 `RotorBearingSimulation`（如
`ALB.build_simulation()`）会以 `ConfigurationError` 拒绝。每个配置应使用独立的
转子对象。

## ROS2 耦合积分器

默认 `integrator: "staggered"` 按上一提交状态计算轴承力并推进转子，轴承力滞后
一步。`"ros2"` 使用两级 Rosenbrock-W 方法（Verwer, Spee, Blom, Hundsdorfer
1999, SIAM J. Sci. Comput. 20(4):1456-1480），在两个 stage 状态同步计算轴承力：

```text
W = I - gamma*h*J,  gamma = 1 + 1/sqrt(2)
W k1 = f(z_j, t_j)
W k2 = f(z_j + h*k1, t_j + h) - 2*k1
z_{j+1} = z_j + h*(1.5*k1 + 0.5*k2)
```

该方法对任意 `J` 保持二阶精度，对精确 `J` 为 L-稳定。`J` 缺省冻结，`W` 只做
一次 LU 分解。耦合状态由连续 ROSS 转子状态 `[q, dq/dt]` 和主动轴承的阀状态组成。
控制器不进入 `J`，在已提交状态每 `m` 步采样一次。

文件配置：

```json5
time_grid: {
  time_step: 2.0e-5,
  steps: 50000,
  integrator: "ros2",
  jacobian_refresh: "control_period",
}
```

`jacobian_refresh` 只能与 `"ros2"` 同时出现。`null` 冻结整个运行的 `J`，正整数
`N` 每 `N` 步在已提交状态重算，`"control_period"` 在任一阀驱动主动轴承
（`pid`、`fuzzy_pid` 或 `uncontrolled`）的每个控制器采样时刻重算；没有这类轴承时
`Ts` 等于步长，每步都重算。刷新只改变稳定裕度和成本，不改变精度阶。

程序化配置可设置全部选项：

```python
import ALB
from ALB.dynamics import Ros2Options

config = ALB.SimulationConfig(
    rotor=rotor,  # Continuous ALB.dynamics.RossRotor
    mounts=(mount,),
    time_step=2.0e-5,
    steps=50000,
    integrator="ros2",
    ros2=Ros2Options(
        jacobian_refresh="control_period",
        jacobian_state=equilibrium_state,
    ),
    initial_rotor_state=equilibrium_state,
)
result = ALB.build_simulation(config).run()
```

`Ros2Options.jacobian_state` 可以是完整转子状态，此时阀状态取 0；也可以是完整
耦合状态 `[转子状态, 阀状态]`。控制器指令取初始状态的采样值。该向量与
`SimulationConfig.initial_rotor_state` 一样保存为浮点数元组，因此 `Ros2Options`
可比较、可哈希，`SimulationConfig` 也能正常做相等比较。长度检查分两步：
`SimulationConfig` 构造时拒绝短于转子状态的向量；没有阀驱动主动轴承时，长度必须
等于转子状态长度，否则同样报 `ConfigurationError`。有阀驱动主动轴承时，阀状态数
要到 runtime 构建后才知道，完整耦合长度在 `run()` 的 reset 阶段检查，不符时
`run()` 以 `SimulationError` 失败。

`relative_step`、`displacement_step`（m）、`velocity_step`（m/s）和 `spool_step`
设置中心差分步长，缺省分别为 `1e-3`、`1e-7`、`1e-4` 和 `1e-3`。runtime 提供
`torch_force` 时，`J` 使用自动微分；自动微分结果非有限时回退到中心差分。当前随包
runtime 都不提供 `torch_force`，因此实际都使用中心差分。`initial_rotor_state`
对两种积分器都可用，用完整 ROSS 状态替换零初始状态。

stage 求力失败时抛出 `ALB.dynamics.ros2.Ros2StageError`，`run()` 将其包装为
`SimulationError`，并保留已提交的部分结果。

## 结果元数据

满足以下任一条件时，`SimulationResult.metadata` 额外记录 `integrator`、
`time_step`、`control_periods`、`time_step_adjustment`、`ros2_options` 和
`initial_rotor_state`：

- 使用 `integrator="ros2"`；
- 声明了控制周期；
- 给出 `initial_rotor_state`。

元数据不保存用户状态向量：`ros2_options` 是 `Ros2Options.to_dict()` 的只读映射，
其中 `jacobian_state` 只记录为 `None` 或 `"user-supplied"`，staggered 运行时整项
为 `None`；`initial_rotor_state` 同样只记录为 `None` 或 `"user-supplied"`；未调整
步长时 `time_step_adjustment` 为 `None`。`SimulationResult.write()` 会把这些嵌套
只读映射序列化为 JSON，控制周期和 ROS2 运行同样可写出制品。默认路径的元数据键和
值保持 0.4.5 不变。

ROS2 的积分计数不写入 `SimulationResult.metadata`，只在内部耦合 runtime
（`ALB.dynamics.coupling._RotorBearingStepRuntime`）的
`diagnostic_snapshot().metadata["ros2"]` 中提供，包括 `state_size`、
`actuator_states`、`rhs_evaluations`、`jacobian_evaluations`、`w_factorizations`、
`control_steps_per_period`、`options`，以及 `direct_spool_hold`（存在 spool
provider 时为 `"zero_order_hold_per_step"`，否则为 `None`）。

## 能力边界

- ROS2 支持无热模型的 `liquid_film`、`gas_film`、`surrogate`（固定或外部阀芯）、
  `multi_pad`，以及无热模型的 `active_lubricated`（`pid`、`fuzzy_pid`、
  `uncontrolled` 和 `external_spool`）。`multi_pad` 的子瓦只能是无热液膜、气膜或
  固定阀芯 surrogate（及其嵌套 `multi_pad`）；含 `active_lubricated` 子瓦或需要外部
  阀芯的子瓦时，在 `SimulationConfig` 构造时以 `ConfigurationError` 拒绝。任何层级
  带 `thermal` 的轴承同样以 `ConfigurationError` 拒绝，因为温度或黏度状态不是转子
  状态的无副作用函数；热模型包装器也显式不提供 `probe_force`，不会把内部等温液膜的
  probe 转发出去。ROS2 还要求连续时间 `RossRotor`；离散转子或缺少 owner hook 的
  自定义转子会被拒绝。
- 外部 spool provider 是耦合状态之外的有状态黑盒，每步在已提交状态采样一次，并在该
  步内零阶保持。因此 provider 通道一般只有一阶精度；只有 provider 指令在步长网格上
  分段常数时，整体才保持二阶。
- 两种积分器的测量时刻不同。staggered 路径中，第 `k` 步的轴承及其内部控制器看到
  第 `k-1` 步提交的转子状态，因此 `t_k` 的控制采样使用 `x(t_k - h)`，与轴承力
  滞后一步相同。ROS2 在 `t_k` 用该时刻提交的状态采样，指令右连续，作用于
  `[t_k, t_k + Ts)`。
- staggered 路径中，阀模型在相邻求值之间对输入做一阶保持插值，新的保持指令会在
  一步内线性进入；ROS2 的阀指令是真正的零阶保持。因此在同一 `Ts` 下比较两种积分器
  的受控响应时，只能期望 `O(h)` 一致；差异不只来自轴承力滞后。
- 冻结 `J` 不影响精度阶，但影响稳定裕度。对标量模型，真实刚度不超过冻结值约 7 倍
  时格式保持稳定。轴颈接近轴承壁面时，油膜刚度急剧增大，裕度下降最多；此时应设置
  `jacobian_refresh` 或减小步长。
- 主动轴承的冻结 `J` 默认在阀状态为 0、控制器指令为初始采样值处计算。要使用非零
  阀状态，需要在 `jacobian_state` 中给出完整耦合状态。
- 打包 surrogate 在轴颈居中处有平方根型刚度奇异，居中状态的差分 `J` 不可靠。
  使用 surrogate 时，应通过 `jacobian_state` 给出偏心状态，例如静平衡状态。
- 自动步长调整会把结束时间向上取整到整数个控制周期，`T <= T' < T + Ts`；`T` 恰为
  `Ts` 整数倍时不变。
- `HistoryPolicy` 的 `downsample` 和 `capacity` 仍按提交索引计数。步长调整后，
  相同索引间隔对应的物理时间随之改变。
- 步长调整会原位重新离散并重置传入的转子对象。同一个转子不要在多个步长不同的
  `SimulationConfig` 之间共享；已被重新离散的共享转子会使原配置在构建 simulation
  时以 `ConfigurationError` 失败。
- ROS2 运行中，主动轴承由积分器持有阀状态，并通过无副作用 probe 求值：probe 把
  限幅后的阀芯开度直接写入各阀对应的节流器输入，阀的生命周期、已发布阀芯和动态
  状态都不变。主动轴承 runtime 自身在运行期间不发布 output 或 result snapshot；
  纯力轴承和直接阀芯轴承仍在每个提交步走正常生命周期。
