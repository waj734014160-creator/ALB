# ALB 0.4.1 数值一致性修复说明

## 文档角色

- 角色：0.4.0 到 0.4.1 的稳定迁移与发布边界说明。
- 允许更新：0.4.1 公共接口、数值合同、移除能力和验收入口。
- 禁止更新：临时测试日志、未执行的通过结论和外部实时状态。
- 事实来源：`ALB/api/analysis.py`、ADR-0007、0.4.1 feature manifest。

## 版本边界

Python 包版本升级为 `0.4.1`。JSON5 `schema_version` 和 surrogate package
格式仍为 `0.4.0`，现有 0.4 配置和模型无需迁移。远端 `v0.4.0`、原 wheel
及其正式验收报告保持不变；0.4.1 取代 0.4.0 作为推荐版本，因为 0.4.0 的
分析 API 验收没有覆盖迁移前核心数值算法的一致性。

## 分析接口变化

- 新增顶层不可变 `ALB.EquilibriumOptions`。`find_equilibrium()` 使用专用
  阻尼 Newton/固定刚度回退算法，任何内层失败或最终不收敛都会抛出带密封
  snapshot 的 `CalculationError`。
- `EllipseTrajectory.orientation_rad` 表示椭圆主轴的空间旋转；`phase`
  只表示时间相位。
- `dynamic_coefficients()` 从同一几何生成正、反涡动并调用既有复数
  `recognize_kc()`；任一样本失败时不发布系数。
- `harmonic_linearize()` 恢复方程导数路径，签名只保留工作点、激励频率和
  external-spool 所需的基准 `spool`。删除错误轨迹拟合方法使用的
  `amplitude`、`points_per_cycle`。
- 谐波线性化只支持有数值合同的量纲 `liquid_film` 和采用三节点
  CSOrifice 的量纲 `active_lubricated`。其他族、无量纲、热包装和未验证
  节流拓扑会明确失败。

## Simulation 与倾瓦

`SimulationConfig` 在运行前要求转子、所有 mount 和嵌套 `MultiPad` 使用同一
`time_step`；控制器、阀和热配置物化时也执行同一不变量。错误信息包含配置
路径。

0.4.1 不支持可倾瓦轴承。相关类、工厂和平衡函数已从安装包物理删除，不提供
别名、私有死代码或兼容转发。未来重新加入时必须作为新功能重新设计并建立
独立数值证据。
