# ALB 0.4.3 数值与输入门禁修复说明

## 文档角色

- 角色：0.4.2 到 0.4.3 的稳定修复与开发验证说明。
- 允许更新：0.4.3 已实现边界、冻结参考、真实开发验证和明确延期项。
- 禁止更新：核心算法替换、未执行的正式发布结论和外部实时状态。
- 事实来源：0.4.3 源码、修复前冻结参考和实际 pytest/mypy 输出。

## 版本边界

Python 包开发版本升级为 `0.4.3`。JSON5 `schema_version` 和 surrogate
package 格式继续使用 `0.4.0`。`v0.4.2`、原 wheel 和正式验收报告保持不变；
当前 0.4.3 尚未形成固定发布候选或标签。

本补丁只修复会影响数值可信度或容易静默改变输入的四项边界，不替换静平衡
Newton、`recognize_kc()`、谐波线性化或液膜核心算法。

## 修复内容

- `SimulationConfig` 要求 rotor 为 dimensional，并在任何 owner reset 前读取
  node 输出，验证其为含 `uxy/uxyt` 的有限 `(node_count, 2)` mapping。coupling
  在 reset 和每次 advance 后再次验证输出。
- 静平衡相对残差优先保留普通 `np.linalg.norm()` 结果；仅在普通范数下溢或
  溢出时使用稳定 `hypot` 路径。归一化载荷模长为零或非有限时在 runtime 创建
  前失败，不再把无定义相对误差解释为零。
- JSON5 禁止对象重复键。bearing/simulation 的时间步不再接受字符串或布尔值，
  simulation 的 `steps`、mount `node`、history `downsample/capacity` 不再通过
  `int()` 静默截断浮点数或布尔值。
- surrogate fixed spool 在配置和 runtime 两层都限制为归一化 `[-1, 1]`，
  与 external-spool 的 `ValveOutput` 边界一致。

## 明确延期

本轮不处理成功 simulation 的 isolated observer 诊断搬运、资源路径 containment、
`SimulationConfig.loads` 深冻结和高层 `BaseException` 异常类型。这些问题不改变
当前有效数值路径，按独立 P3 维护范围处理。
