# ALB 0.4.7 预测-校正分区耦合

参考来源：`ALB/dynamics/predictor_corrector.py`、`ALB/core/checkpoint.py`、
  `ALB/contracts/bearing.py`、`ALB/api/simulation.py`、`ALB/api/building.py`、
  `docs/adr/0010-predictor-corrector-coupling-and-bearing-checkpoints.md` 和 0.4.7 参考测试。

## 版本边界

Python 包版本为 `0.4.7`，JSON5 `schema_version` 和 `ALB.SCHEMA_VERSION` 继续为
`0.4.0`。`time_grid.integrator` 增加取值 `"predictor_corrector"`，并新增可选字段
`time_grid.predictor_corrector`。新增根符号 `ALB.CouplingIterationWarning`，根 API 共
29 个符号；新增高级导出 `ALB.dynamics.PredictorCorrectorOptions` 和契约
`ALB.contracts.CheckpointableRuntimeProtocol`。合法的 0.4.6 配置无需迁移；不选新格式
时 staggered 与 ROS2 的数值结果、结果元数据和 `result.write()` 文件集合与 0.4.6 逐位
一致。决策依据见 ADR-0010。

## 预测-校正格式

默认 staggered 格式的轴承力滞后一步（一阶）；ROS2 消除了滞后但要求无副作用的力和
雅可比（0.4.6 标记为功能不完善）。`"predictor_corrector"` 在保持轴承黑箱的前提下消除
滞后：每步先预测界面力，再用“从已提交状态出发、不提交”的轴承试算校正，必要时迭代到
界面一致，最后每个轴承只提交一次：

```text
P^0     = 2 F_n - F_{n-1}（predictor="linear"）或 F_n（"constant"）
x^k     = Prop(x_n, G_n, L(t_{n+1}) + M P^k)          转子试算
F~^k    = Trial(y(x^k); t_{n+1})                      轴承试算
r^k     = F~^k - P^k                                  ||r^k||_inf <= rtol max(||F~^k||_inf, f_ref) + atol
x_{n+1} = Prop(x_n, G_n, L(t_{n+1}) + M F~^k)
F_{n+1} = Commit(y(x_{n+1}); t_{n+1})
```

`f_ref = max(||F_n||_inf, 1 N)`。`mode="pece"` 每步恰好 1 次试算和 1 次提交，不检查
收敛；`mode="iterate"`（默认）迭代到容差或 `max_iterations`。PECE 与迭代版在线性、硬化、
记忆解析算例及 `m = 1` 的采样主动算例上都是二阶，staggered 为一阶；`m > 1` 时阀的一阶保持
插值使阀芯通道降为一阶（见“与控制周期结合”）。

程序化配置：

```python
import ALB
from ALB.dynamics import PredictorCorrectorOptions

config = ALB.SimulationConfig(
    rotor=rotor,  # ALB.dynamics.RossRotor
    mounts=(mount,),
    time_step=2.0e-5,
    steps=5000,
    integrator="predictor_corrector",
    predictor_corrector=PredictorCorrectorOptions(
        mode="iterate",
        relaxation="aitken",
        rtol=1.0e-6,
        atol=1.0e-6,
        max_iterations=20,
        on_nonconvergence="warn",
    ),
)
result = ALB.build_simulation(config).run()
print(result.metadata["predictor_corrector_diagnostics"]["iterations_per_step"])
```

文件配置：

```json5
time_grid: {
  time_step: 2.0e-5,
  steps: 5000,
  integrator: "predictor_corrector",
  predictor_corrector: {
    mode: "iterate",
    predictor: "linear",
    relaxation: "aitken",
    omega: 0.5,
    omega_bounds: [0.01, 1.5],
    iqn_reuse_steps: 0,
    rtol: 1.0e-6,
    atol: 1.0e-6,
    max_iterations: 20,
    on_nonconvergence: "warn",
  },
}
```

`predictor_corrector` 只能与 `integrator: "predictor_corrector"` 同时出现；省略或写
`null` 时使用全部默认值。`mode="pece"` 时 `relaxation`、`omega`、`omega_bounds`、
`iqn_reuse_steps`、`rtol`、`atol`、`max_iterations` 和 `on_nonconvergence` 仍会校验，
但不起作用，`to_dict()["unused_in_pece"]` 列出这些字段。`rtol` 不宜小于轴承求解器自身的
相对容差（FEM 液膜约 `1e-6`），否则求解器噪声会使迭代无法收敛。

### 松弛与收敛

| `relaxation` | 更新 | 说明 |
| --- | --- | --- |
| `"aitken"`（默认） | `P + ω_k r`，`ω_k = -ω_{k-1} r_{k-1}ᵀ(r_k - r_{k-1}) / ‖r_k - r_{k-1}‖²` | 截断到 `omega_bounds`；每步首次更新沿用上一步最后的 `ω`（首步用 `omega`） |
| `"iqn_ils"` | `P = F~^k + W c`，`c = argmin ‖V c + r^k‖` | 首次更新用 `omega`；`|R_ii| < 1e-10 ‖r^k‖` 的列丢弃；`iqn_reuse_steps` 复用前几步的列 |
| `"constant"` | `P + ω r` | 固定 `omega` |
| `"none"` | `P = F~` | 只有一步映射为压缩映射时收敛 |

不加松弛时收敛条件为 `ρ(∂F/∂y · ∂y/∂P) < 1`，`∂y/∂P` 对位移约 `h²/(6m)`、对速度约
`h/(2m)`（`m` 为轴颈处等效质量）。刚度大、尤其阻尼大的油膜在实用步长下可能 `ρ > 1`，
此时 `"none"` 与 PECE 发散或失稳，应使用 `"aitken"` 或 `"iqn_ils"`，两者都不需要导数。

### 不收敛与失败

- `on_nonconvergence="warn"`：达到 `max_iterations` 仍未收敛时提交最后一次迭代；整个运行
  只在第一次发出 `ALB.CouplingIterationWarning`（`UserWarning`，不是 `ALBError`），不收敛
  步数与最大残差记入诊断。
- `on_nonconvergence="raise"`：抛出 `ALB.dynamics.predictor_corrector.CouplingIterationError`，
  `run()` 包装为 `SimulationError` 并保留已提交的部分结果。
- 试算中轴承抛出异常（如热迭代不收敛）时，轴承先回退到本步开始时的提交状态，再以
  `CouplingTrialError` 封存该步失败；不静默重试，也不自动减小步长。NaN 或 Inf 同样按
  失败封存，异常类型取决于出现位置：转子试算状态、直接探测的力或界面更新非有限时为
  `FloatingPointError`；存档试算或经单位适配器的试算力由输出 DTO 校验拒绝，包装为
  `CouplingTrialError`；提交求值的非有限力由轴承输出 DTO 校验报 `ValueError`。

## 存档/回退协议

无副作用的轴承用 `probe_force` 试算；带内部状态的轴承实现
`CheckpointableRuntimeProtocol`：

```python
class CheckpointableRuntimeProtocol(Protocol):
    def checkpoint(self) -> object: ...      # opaque token of the committed state
    def restore(self, token: object) -> None: ...
```

“存档 → 任意次试算 → 回退 → 正常求值”与“直接正常求值”逐位相同。令牌可重复回退，
试算失败后同样可回退；令牌只能回退到创建它的 runtime。复合轴承委托给子对象的令牌。

| 轴承族 | 试算方式 | 存档覆盖的状态 |
| --- | --- | --- |
| 无热液膜、气膜、固定阀芯代理及其多瓦 | `probe_force` | —（也实现了协议，供含有状态子瓦的多瓦委托） |
| 外部阀芯代理、`ALBSV`/`NodimALBSV`（无热） | `probe_force`，阀芯来自 provider | — |
| 液膜 + 热（稳态、瞬态，量纲/无量纲） | 存档/回退 | `_temperature_prev`、`_last_thermal`、热网格与后处理记录、热配置；内部液膜的模型参数、压力迭代、节点压力/膜厚/粘度比、膜厚模型、后处理缓存、节流器缓冲、可选保存历史；生命周期与最新输出/结果/收敛状态 |
| `ALB`/`NodimALB`（`pid`、`fuzzy_pid`、`uncontrolled`，含带热瓦） | 存档/回退 | 控制器积分/差分记忆、结果记录与生命周期；`_control_counter`、`_held_command`、控制开关；动态与静态伺服阀的状态、一阶保持输入记忆与历史；阀连接的节流器；各瓦的令牌 |
| `ALBSV`/`NodimALBSV` 带热瓦 | 存档/回退 | 同上，另含直接阀芯 |
| 含有状态子瓦的 `multi_pad` | 存档/回退 | 复合体生命周期与各子瓦令牌 |

元素矩阵和全局装配矩阵每次求解都从当前膜厚重建，属于求解器临时量，不存档。外部阀芯
provider 若实现 `checkpoint()`/`restore()`，每次试算都用试算输入调用并与轴承一起回退；
否则与 ROS2 相同，在每次提交时采样一次，试算使用该阀芯并保持，阀芯通道为一阶精度。

显式状态模型（例如热记忆 MLP、LSTM 的 `(h, c)`）实现协议时，只需把显式状态复制进
令牌并在 `restore` 中写回，见 ADR-0010。

## 与控制周期结合

控制周期校验和步长调整对新格式同样适用。主动轴承的控制器按提交次数计数，试算被回退，
因此控制器恰好每 `m` 次提交执行一次；迭代收敛后，`t_k` 的采样使用该时刻的提交状态，
与 ROS2 一致。阀模型对输入指令做一阶保持插值，`m > 1` 时采样时刻的指令跳变被摊到前一步
内（约提前半步），阀芯通道降为一阶；`m = 1` 时为二阶。

## 结果元数据

只有预测-校正运行额外记录：

- `integrator`、`time_step`、`control_periods`、`time_step_adjustment`、`ros2_options`
  （为 `None`）、`initial_rotor_state`（与 0.4.6 的非默认运行相同）；
- `predictor_corrector_options`：`PredictorCorrectorOptions.to_dict()` 的只读映射；
- `predictor_corrector_diagnostics`：`steps`、`trial_iterations`、`trial_evaluations`、
  `commits`、`commit_evaluations`、`iterations_per_step`（`mean`、`max`、`histogram`，
  直方图为 `(试算次数, 步数)` 对）、`nonconverged_steps`、`max_final_residual`、
  `max_consistency_residual`、`residual_ratio`（相邻残差之比的 `mean`、`max`、`count`）、
  `aitken_omega_range`、`trial_modes`（`"probe"` 或 `"checkpoint"`）和 `spool_trials`
  （`"provider_checkpoint"`、`"held_per_step"` 或 `None`）。

失败快照的元数据同样带有这两项；以失败结束的那一步也计入诊断（`raise` 的不收敛步计入
`nonconverged_steps`，已完成的试算计入 `trial_iterations` 和直方图），`iterations_per_step`
按尝试过的步数统计。默认 staggered 路径的元数据和 `result.write()` 文件集合
不变；ROS2 与控制周期运行保持 0.4.6 的键集合。

## 能力边界

- 支持全部随包轴承族：`liquid_film`（含稳态/瞬态热）、`gas_film`、`surrogate`（固定或
  外部阀芯）、`active_lubricated`（`pid`、`fuzzy_pid`、`uncontrolled`、`external_spool`，
  含热）及其 `multi_pad`。唯一拒绝的拓扑是 `multi_pad` 内需要外部阀芯的子瓦（复合体没有
  spool provider），在 `SimulationConfig` 构造时以 `ConfigurationError` 拒绝并写明路径。
- 需要提供 owner hook `_propagate_trial`、`_node_state_indices`、`_node_force_vector`、
  `_commit_integrated_state` 的转子（`RossRotor`，连续或离散）。离散转子的
  `results()`/`result_uxy()` 输出与提交状态对齐，而 staggered 离散路径输出上一步状态。
- 既不能探测也不能存档的自定义 runtime，以及子瓦不支持存档的复合体，在 reset 时以
  `TypeError` 拒绝。
- 外部载荷用不写日志的 `force_at` 计算，与 ROS2 相同；`UnbalancedExcitation.results`
  只记录 reset 时 `t0` 的初始载荷，不记录步进中的载荷。
- 带液膜节流器的无热液膜用 `probe_force` 试算：节流器滚动缓冲只影响下一次提交求解的
  停止迭代次数，差异在求解容差内（与 0.4.6 ROS2 相同）。
- 主动轴承的阀对输入做一阶保持插值，`m > 1` 时阀芯通道为一阶（见上文）。
- 代理模型（ALBNN）族只做了接口层验证；真实模型的数值核对由用户在本地完成。
